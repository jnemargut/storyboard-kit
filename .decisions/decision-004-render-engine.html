Each part, bubble and device is an SVG element generated straight from the JSON by React components. A separate transparent layer on top holds the selection handles, snapping guides and text boxes. This is the same architecture tldraw uses internally, without the license. Text editing is ordinary HTML, SVG export is nearly free because the art already is SVG, and the marker wobble filter is applied once per panel and paused while you drag.

Works well when

  • The rig, marker filters and hand-lettering are all native SVG
  • Bubbles get real text editing, wrapping, spellcheck and accessibility
  • Open-source friendly: no license keys, no watermark

Watch out for

  • You build selection, snapping, undo and zoom yourself (about 2–4 weeks)
  • SVG slows down at thousands of moving parts (storyboards are around 400)

Everything is painted onto a single canvas bitmap. Konva gives you drag, resize and rotate handles out of the box, and it stays fast with thousands of objects. But the marker wobble has to be re-created in canvas code, text editing is a known pain (a floating textarea that drifts when you zoom or rotate), and you lose SVG export.

Works well when

  • Drag and transform handles come built in
  • Performance headroom for huge boards

Watch out for

  • Konva's own docs say canvas isn't designed for text editing
  • SVG filters don't carry over, so the look is rebuilt by hand
  • No vector export for designers who want to bring boards into Figma

You'd write custom shapes for characters, bubbles and panels and get a polished editor in days. But since SDK 4.0, production use needs a license key (reported around $6k per team per year), or a watermark and a non-commercial hobby license. Excalidraw is MIT-licensed and loved, and its hand-drawn look is close in spirit. But it only knows a fixed set of shapes (rectangle, ellipse, arrow, text, image). A rigged character, a device with a screen slot, or a speech bubble that follows its speaker can't exist as a native element, so they'd become flat images and the editing would stop at "move the picture".

The case against my pick

Building your own editor is a known tar pit. Selection, multi-select, snapping, undo/redo, zoom and pan, keyboard shortcuts and touch support are each "a few days" that add up to months, and it's the least differentiating part of this tool. tldraw (C) exists precisely so people stop rebuilding it. If this tool ends up internal to one company rather than open source, the license cost is small next to the engineering time, and C becomes the better choice.

This recommendation assumes

  • The tool is distributed free and open source, so anyone can npx it without a license key
  • Boards stay around a dozen panels with a few hundred parts, well under where SVG gets slow
  • You're willing to spend about 2–4 weeks on editor basics (a library such as react-moveable can cover the handles)

What the research says

  • tldraw renders every shape as an SVG or HTML React component to get DOM events, CSS, text input and accessibility, which is option A's architecture inside a product. tldraw docs
  • Since SDK 4.0 (Sept 2025), tldraw needs a license key in production (reported around $6k per team per year, now "custom pricing"). The hobby license is non-commercial and requires a watermark. tldraw license BigGo
  • Felt moved from SVG to canvas because React re-checking thousands of nodes on every pan broke large maps. That's the ceiling for A, and far above a storyboard's size. Felt
  • DOM/SVG animation stays smooth to about 100 objects moving at once and degrades around 500. In a storyboard you drag one thing at a time. web animation benchmark
  • SVG turbulence filters are expensive, especially on iOS and Firefox. The fix is one filter per panel group, switched off while dragging. GSAP forum Mozilla #422371
  • Konva recommends a textarea positioned over the canvas for text editing. Users report it drifts on zoom and rotate. Konva docs konva #878
  • Excalidraw's element types are fixed. Custom elements have been requested since 2022. excalidraw #4957
